# Переключение режима поиска

Готовые файлы для текущего фронтенда `mialzh/local-search`, ветка `vector-search`.

Под поисковой строкой появился переключатель в текущем стиле:

- **По словам** — обычный поиск через `GET /search`.
- **По смыслу** — векторный поиск через `GET /search/vector`.

При смене режима введённый запрос выполняется заново. Предыдущий запрос отменяется; его ответ не может заменить новую выдачу. Режим, запрос и количество результатов сохраняются в адресе страницы и при возврате из документа.

Клиент учитывает разные форматы ответа: `score` для обычного поиска и `distance` для векторного. Порядок результатов сохраняется таким, каким его вернул сервер. В поиске по словам остаётся подсветка совпадений; в поиске по смыслу текст показывается без подсветки отдельных слов. Светлая и тёмная темы используют текущие цвета приложения.

## Установка

Скопируй содержимое архива в корень проекта с заменой одноимённых файлов, сохранив структуру каталогов.

Если архив находится в `/work/frontend-search-modes.zip`, в devcontainer можно выполнить:

```bash
cd /work
unzip -o frontend-search-modes.zip
```

Затем открой `http://localhost:8080` и обнови страницу сочетанием **Ctrl+F5**. При работающем сервере текущий `fs-cache-web` подхватывает изменения примерно за секунду. Пересобирать C++ для этих изменений не требуется.

Обновлены шесть файлов фронтенда:

- `web/index.html`
- `web/styles.css`
- `web/app.mjs`
- `web/api.mjs`
- `web/document.html`
- `web/document-page.mjs`

Остальные существующие файлы в `web/` нужны для работы приложения и остаются на месте.

Дополнительно обновлён `tests/web/api.test.mjs`. Проверки клиента и подсветки:

```bash
node --test tests/web/*.test.mjs
```

Проверено: 27 тестов клиента и подсветки, а также программные сценарии переключения режима, отмены запросов, восстановления состояния из URL, пустой выдачи и недоступности векторного сервиса. Визуальная проверка в браузере в среде подготовки недоступна. Проверка с твоим живым сервером выполняется после копирования файлов.
